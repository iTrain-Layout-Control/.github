## iTrain Highlights

- **Layout Control:** iTrain layout control puts the track diagram, trains, and switches on one screen so a home layout can be run without hunting through separate panels.
- **Block System:** iTrain block system divides the railroad into sections that know when a train is present, which keeps following trains from closing up by accident.
- **Locomotive Cab:** iTrain locomotive cab gives one engine speed, direction, and lights while the rest of the layout stays visible behind it.
- **Turnout Route:** iTrain turnout route lines up the switches for a path you named, such as from the yard to the main, so you do not throw each turnout by hand.

## What Is iTrain

iTrain is a model railroad helper for people who run trains on a layout they can walk around. iTrain layout control is the main view: the drawing of the track, the trains sitting on it, and the turnouts that choose a path. A bedroom layout, a garage railroad, or a club corner can use the same idea. You select a locomotive, choose a direction, and watch the diagram instead of guessing which wire does what.

iTrain block system is what makes that diagram useful once more than one train is moving. Each block reports whether it is busy. iTrain locomotive cab then lets you drive one engine with a clear speed control while the blocks show where the other train is. iTrain turnout route stores a path through the switches so a repeated move, such as leaving the staging yard, happens the same way each time. None of this asks for a large exhibition hall. A modest home layout is enough to learn the rhythm.

iTrain auto drive builds on those pieces. After the blocks, the signals, and the route look right, a train can proceed on its own while you watch. That is handy for a study hour about how blocks work, or for a small club night when one person wants a train circulating while another switches cars. iTrain layout control, iTrain block system, and iTrain locomotive cab stay available the whole time, so automatic running never hides the manual controls. People keep iTrain turnout route and iTrain auto drive for the repeatable parts, and they drive by hand whenever a move needs a closer look.

## Starting with iTrain

Prerequisites: A compatible computer, a command station you already use with the layout, and permission to run iTrain.

1. **Prepare:** Draw the loops and sidings on paper so the first iTrain layout control view matches the room.
2. **Place Blocks:** Mark the stopping sections and confirm iTrain block system shows a train when it enters one.
3. **Drive One Engine:** Open iTrain locomotive cab and run a single locomotive around an empty loop.
4. **Store A Path:** Create one iTrain turnout route from the yard to the main and throw it twice to be sure.
5. **Try A Short Run:** Use iTrain auto drive on that route only after the manual trip looked right.
6. **Add The Next Train:** Bring in a second locomotive only when the first blocks and the route feel familiar.
